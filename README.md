# Online Hospital Appointment Booking System

## Project Description
The Online Hospital Appointment Booking System is a Python
application that allows patients to book, view, and cancel
hospital appointments.

## Features
- Book a doctor appointment
- Validate required fields
- View appointments
- Cancel appointments
- Automated unit testing

## Technologies Used
- Python
- Git
- GitHub
- Jenkins

## Project Structure
- src/app.py: Application source code
- tests/test_app.py: Unit tests
- Jenkinsfile: CI pipeline configuration

## Run the Application
python -m src.app

## Run Tests
python -m unittest discover -s tests -v

## Bug Fix
Validate appointment details before booking.

## Feature
Patients can book hospital appointments online.

## Online Appointment Booking Feature
- Patients can request hospital appointments online.
- Appointment details are validated before booking.
- The feature is developed and tested before merging into main.
